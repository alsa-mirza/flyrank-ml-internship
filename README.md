# FlyRank ML Internship Capstone

## Applied Search Intelligence: Google Search Ranking & Discoverability

## Project Overview
This project was developed as part of the FlyRank Machine Learning Internship Capstone.

The goal of this project is to analyze search performance data and build a machine learning solution that identifies content opportunities and provides actionable recommendations for improving search discoverability.

## Problem Statement
Search performance depends on multiple factors such as impressions, clicks, ranking position, and engagement signals. The objective of this project is to build a model that helps prioritize pages requiring optimization.

## Machine Learning Approach
The project follows an ML workflow:
- Problem framing
- Data exploration
- Feature engineering
- Baseline scoring
- Model development
- Evaluation
- Action recommendations

## Model Used
### Random Forest Model
A Random Forest based model was trained to identify important patterns from search performance features and generate ranked recommendations.

## Features Used
Some important features include:
- Impressions
- Click Through Rate (CTR)
- Average Position
- Search performance metrics
- Content-related signals

## Results
The model was evaluated to identify high-impact optimization opportunities and generate actionable search intelligence insights.

## Recommendations
The final output provides prioritized actions such as:
- Improving metadata
- Optimizing underperforming content
- Focusing on high-impression opportunities
